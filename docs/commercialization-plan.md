# Commercialization Plan

## Math Intellect — Current Position and Future Commercial Path

**Document status:** Proposed commercialization strategy. The current cloud MVP is live for technical/reviewer testing; this document does not claim existing sales, paid users, school contracts, or institutional deployment.

## Current Product Position

Math Intellect currently operates as a cloud-deployed functional MVP using:

- LINE Official Account / Messaging API
- n8n Cloud
- OpenAI API
- JavaScript workflow logic
- multi-stage AI review
- public GitHub technical documentation

The current deployment demonstrates technical operation. It is not yet a complete commercial SaaS service.

## Current Evidence

Current technical evidence includes:

- live reviewer testing through LINE;
- n8n Cloud deployment;
- sanitized workflow export;
- GitHub documentation;
- short demonstration video;
- frozen 51-case validation baseline;
- selected current regression tests.

The historical validation baseline identified substantial visual/diagram interpretation weakness. Later selected tests and cloud deployment do not replace those metrics.

## Current Capability Boundary

The system can process mathematics questions containing diagrams or graphical information when interpretation succeeds.

If the final answer requires a rendered visual output, the current stable MVP provides text-based drawing instructions. Generated visual rendering remains under development.

The project does not yet include:

- paid subscription infrastructure;
- persistent learner records;
- teacher dashboard;
- school administration;
- production-grade monitoring;
- service-level commitments;
- proven educational impact;
- demonstrated commercial demand.

## Potential Customer Segments

| Segment | Potential value | Current status |
|---|---|---|
| Individual learners | On-demand structured mathematics support | Functional MVP available for testing |
| Teachers / tutors | Structured solution and assessment-support workflow | Future product expansion |
| Learning centres / schools | Supervised learner support and productivity tools | No institutional deployment yet |

## Proposed Development Path

### 1. MVP reliability

Continue regression testing, failure analysis, diagram/graph handling, visual-output development, and monitoring.

### 2. Teacher productivity tools

Develop worksheet/question generation, dashboards, PDF/report delivery, and workflow features for educators.

### 3. Controlled pilots

Conduct supervised teacher/learning-centre pilots after privacy, access, monitoring, and support processes are ready.

### 4. Commercial service

Consider pricing and subscription models only after actual operating cost, usage, user feedback, and product reliability are measured.

## Potential Revenue Models

Future possibilities include:

- individual subscription;
- teacher/tutor professional plan;
- learning-centre licensing;
- school/institutional licensing;
- custom implementation or support.

These are proposed models, not current revenue.

## Operating Cost Considerations

Commercial operation would need to account for:

- OpenAI API usage;
- n8n/cloud hosting;
- LINE messaging usage;
- monitoring;
- support;
- development and maintenance;
- data/privacy operations;
- educator review.

## Commercial Evidence Boundary

A working cloud MVP demonstrates recent digital-product development and technical feasibility. It does not by itself prove product-market fit, learning outcomes, institutional readiness, or sustainable unit economics.
