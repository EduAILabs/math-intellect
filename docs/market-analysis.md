# Market Analysis

## Math Intellect — Current MVP and Potential Market

**Document status:** Market framing and future opportunity. The current cloud MVP demonstrates technical operation, not validated market demand.

## Current Product Status

Math Intellect is currently a cloud-deployed functional MVP available through the Math Intellect LINE Official Account.

Current implemented capabilities include image-based question intake, n8n Cloud orchestration, AI-assisted mathematics processing, quality review, failure routing, and LINE response delivery.

The current system is not yet a production institutional platform.

## Primary User Groups

### Students

Potential needs:

- immediate support outside lesson hours;
- structured working;
- examination-oriented guidance;
- accessible messaging-based interaction.

### Teachers and tutors

Potential needs:

- structured solution support;
- assessment-oriented review;
- future productivity tools;
- future worksheet/question generation.

### Schools and learning centres

Potential future needs:

- supervised learner support;
- consistent educational workflows;
- teacher productivity tools;
- institution-level administration;
- analytics and reporting.

The current MVP does **not** yet provide school administration or institution-level deployment.

## Current vs Future Capability

| Area | Current | Future |
|---|---|---|
| Question intake | LINE image submission | Wider interfaces |
| Workflow hosting | n8n Cloud live MVP | More complete production SaaS operations |
| Mathematics response | Structured text response | Broader output formats |
| Diagram-containing input | Can be processed when interpreted successfully | Wider validated coverage |
| Final rendered visual answer | Text drawing instructions | Generated diagram/graph rendering |
| Learner history | Not implemented | Persistent records |
| Teacher tools | Limited | Dashboard and productivity tools |
| Institutional delivery | Not implemented | Controlled pilots and administration |

## Market Evidence Boundary

The current cloud deployment demonstrates a working digital product and enables live testing.

It does not yet establish:

- product-market fit;
- willingness to pay;
- user retention;
- school demand;
- commercial traction;
- learning outcomes.

Those require separate market and educational validation.

## Potential Commercial Direction

Possible future models include:

- B2C learner subscription;
- teacher/tutor professional tools;
- learning-centre licensing;
- school/institutional licensing.

Any pricing or revenue assumptions should be tested against real usage and operating costs.

## Key Risks

- mathematical/interpretation errors;
- diagram and visual-output limitations;
- privacy and safeguarding requirements;
- AI/API operating cost;
- platform dependency;
- institution-specific requirements;
- unvalidated market demand.

## Next Market-Validation Step

After technical reliability is strengthened, the project may move toward supervised educator and learning-centre pilots with clear feedback, privacy, and success criteria.
